- **apps/api**

## 修复：Qwen Image 2.0 Pro / GPT Image 2 未上架广场
- 根因：生图能力只在 `apps/api/src/workflow/image-service.ts`（`IMAGE_GENERATION_MODELS=[qwen,gpt,doubao]`）接入，但 billing seed 只加了豆包，Qwen/GPT 缺 `PriceRule` 广场行，故不显示。
- 关键确认：`ListMarketplace()` 仅按 `enabled AND show_in_marketplace` 过滤（不含 `output_price>0`），零价格生图模型可正常进广场；而 `ListEnabled()` 带 `output_price>0` 过滤仅用于 chat 选择器，不影响广场。
- `services/billing/internal/registry/registry.go` 的 `SeedDefault` 新增 Qwen（`qwen-image-2.0-pro-2026-04-22`，env `QWEN_IMAGE_MODEL` 可覆盖）与 GPT（`gpt-image-2`，env `GPT_IMAGE_MODEL` 可覆盖）两个生图 seed：同豆包结构（`视觉模型` 分类、`image-gen,vision` 标签、`ShowInMarketplace:true`、零 token 价），sort 101/102。模型 ID 与 image-service 常量严格对齐，生图工作台才能加载配置。
- `codex-pet-routes.ts` 生图列表仍排除豆包、保留 Qwen/GPT（二者支持参考图编辑），无需改动。
- 新增回归测试 `TestListMarketplaceIncludesZeroPriceImageGenModels`（零价格 image-gen 模型须被 `ListMarketplace` 返回）；`go build` + registry 测试全过。
- 运营注意：改动生效需重启 billing 服务触发 `SeedDefault`（幂等，存量模型不覆盖）。
