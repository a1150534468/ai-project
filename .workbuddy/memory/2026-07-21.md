## 第二版：恢复间距（用户反馈「不好看，gap 都没了」）

第一版把 `h-full` 一路强制到 studio 根，导致卡片直接贴屏幕四边、与顶栏之间也无留白，用户觉得丢失了间距。第二版修复：

- `Workflow.tsx`：新增 `studioWrapperClass`。
  - image / commerce-long-image / codex-pet 的 studio 包裹层加页面级留白 `px-4 py-4 lg:px-6 lg:py-5`，让白色圆角卡片浮在灰底上、四周与顶栏之间都有间距（恢复原来缺失的 gap）。
  - novel 包裹层保持 `h-full` 无缩进（NovelWorkbenchShell 自带全屏外壳，已处理留白）。
  - 全屏 commerce 侧栏补回 `p-3`（全屏抽屉化时误删）。
  - 内层容器 `h-full` 改为 `xl:h-full`：≥xl 固定全屏、各栏内部滚动；<xl 退化为整页滚动，避免内容被裁切。
- 各 studio 根节点与卡片栏的 `h-full` 全部改为 `xl:h-full`（仅 ≥xl 强制高度），<xl 自然撑高、整页滚动。涉及 ImageWorkflowStudio / CommerceImageStudio / EcomMainImageStudio / ecomWorkflowStudioView / CodexPetStudio（其 3 栏 `space-y-3` 容器加 `xl:h-full`）。
- 各栏内部 `gap-5` / `gap-3` 卡片间距原本就保留，无需动。

验证：`typecheck` 与 `build`（878 模块）均通过。

经验：全屏工作区要让「卡片浮在灰底 + 页面 padding」而不是「卡片贴边」。高度锁定只应在 `xl:` 断点生效，否则窄屏会裁切。
