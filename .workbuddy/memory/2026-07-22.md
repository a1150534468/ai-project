## 生图 key 配置位置答疑 + 补全 ARK_API_KEY
- 用户问"key 在哪配置，找不到地方"。结论：所有上游 key 都是环境变量，**无 admin UI**。
  - K8s：编辑 `infra/k8s/secrets.env.example` → `secrets.env` → `create-secrets.sh` 写入 k8s secret。
  - 本地：`apps/api` 通过 `src/env.ts` 自动加载仓库根 `.env.local`/`.env`。
- 根因：`ARK_API_KEY`（豆包生图）此前**未写入** `secrets.env.example` 和 `create-secrets.sh` 的 `API_KEYS`，故用户找不到。
- 修复：在 `infra/k8s/secrets.env.example`（api 段，GPT_IMAGE_API_KEY 后）新增 `ARK_API_KEY=` 与可选 `ARK_IMAGE_ENDPOINT=`；并在 `create-secrets.sh` 的 `API_KEYS` 数组追加 `ARK_API_KEY ARK_IMAGE_ENDPOINT`。
- 顺带说明各生图模型 key 映射（见 MEMORY.md）：豆包=ARK_API_KEY；Qwen=IMAGE_API_KEY 或复用 BAILIAN_API_KEY/DASHSCOPE_API_KEY；GPT=GPT_IMAGE_API_KEY。
- 新建项目级 `MEMORY.md`，固化"生图 key 配置约定"与"模型广场数据链路"两条长期约定。
